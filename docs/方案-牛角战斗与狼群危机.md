# 牛角战斗与狼群危机 —— 评估与实施方案

**基准代码**：`D:\牛来`（Godot 4，游戏「牛走/大梦哞哞」）
**评估对象**：外部方案《荒诞物理 × 生存危机：牛角战斗 + 狼群危机 + 配套道具》
**结论先行**：方案与现有架构契合度约 70%，核心机制（血条冲撞、狼群刷新、处决、掉落物）全部有现成代码模板可复用，建议按 P1→P2→P3 三期落地。用户提出的两个痛点——**树不能穿模**（根因已定位，改动量约 10 行）和**技能效果弱**（根因：冲撞判定只处理 RigidBody，对 NPC 生物完全无效）——放在 P1 最优先解决。

### 1.3 用户两个痛点的根因（代码级定位）

**① 树不能穿模、没啥东西能穿模**

根因在 `world/grassland.gd`：
- 冲撞穿模的实现是 `player/cow.gd` L213：`collision_mask = 1`（摘掉脆弱层 bit 3）→ 只能穿过 `collision_layer = FRAGILE_LAYER(4)` 的物体
- 但全地图只有**隐藏区四面墙**（`_build_secret_area()` L396）设了 `collision_layer = FRAGILE_LAYER`
- **36 棵静态树是默认层 1**（`_build_trees()` 创建的 StaticBody3D 没设 layer），6 块静态大石也是——所以冲撞撞树=撞墙，毫无穿模可言
- 结论：不是穿模机制弱，是**能穿模的物体太少**（只有4面墙）。修复=给树/石头加上脆弱层

**② 技能效果都有点弱**

根因在 `player/cow.gd` `_on_charge_hit()`（L240-265）：冲撞命中只处理三种情况：
1. `RigidBody3D` → 击飞+扭矩（爽点，但只有4棵动态树+8块小石+草堆道具）
2. `BoulderBoss` → 扣耐心
3. `ChaosBlackhole` → 撞碎

**对 CharacterBody3D（NPC牛、大逃杀陪练牛、未来的狼）完全不生效**——冲撞穿过它们像穿过空气。没有伤害数值、没有击退、没有血条，所以"感觉弱"。

## 二、P1 核心机制（先做这两个：穿模升级 + 牛角处决 & 狼刷新）

### P1-A 穿模升级（用户痛点，改动最小收益最大）

**改动文件**：`world/grassland.gd`（约10行）、`player/cow.gd`（几行反馈）

1. 静态树加脆弱层：`_build_trees()` 的 else 分支（静态树）加 `tree.collision_layer = 1 | FRAGILE_LAYER`
   - 效果：平时树是实体的（层1仍在），冲撞/幽灵药水期间直接穿过去
2. 静态大石同理：`_build_rocks()` 的静态石加层
3. 穿树视觉反馈（廉价但上头）：穿模瞬间树冠抖动（Tween 快速摇摆 rotation.z ±0.15）+ 掉 3 片"叶子"（CPUParticles3D 或直接复用草丛锥体 mesh 掉落），配文案"你穿过了树。树的感受不得而知。"
4. 穿模药水（potion）描述升级兑现：现在真的能"穿过一切讲道理的东西"了——树、石头、墙、**NPC**
5. 狼的"穿模地形杀"（原方案：狼飞扑瞬间玩家穿模遁地→狼卡地里）依赖此改动：狼的扑咬判定用 Area3D，玩家幽灵化期间狼扑空 → 狼前冲进地形 → 卡住 3 秒后"咻"消失（复制 npc_cow 半埋牛演出）

**验收**：冲撞能穿过任意树/石；穿模瞬间有树冠抖动反馈；隐藏区依旧正常。

### P1-B 牛角战斗系统（角=伤害等级，3格血+处决）

**改动文件**：`player/cow.gd`、`player/cow_model.gd`、`ui/game_hud.gd`、新建 `chaos/horn_system.gd`（或直接挂 PlayerCow）

1. **角等级**（局内成长，0/1/2 三档）：
   - 0 无角（开局）：冲撞=纯击退，0 伤害——现状手感不变
   - 1 初级角：吃 5 个**发光石笋**（地图新物件： emissive 圆锥，随机散布 9-12 个，复用金草的自发光材质）→ "角芽"动画（头顶冒出两个小圆锥，Tween 弹出）
   - 2 狂暴角（60秒限时道具）：狼骨粉触发，角变黑变大，伤害翻倍，冲撞后自己原地转圈晕 1 秒（负收益换爆发，符合"廉价但上头"）
   - **黄金牛角**（彩蛋级）：地图最深处 (-85,-85) 放一个黄金牛角拾取点，旁边蹲一只复用 BoulderBoss 的"巨石牛看守"（换皮：灰色 CowModel 放大 3 倍+耐心5）——用飞天（连跳3次）或穿模药水偷。偷到=局内永久狂暴角+金色牛身特效
2. **血量系统**（3 格，所有可战斗生物统一）：
   - 玩家：HUD 左上角 3 个奶瓶图标（`game_hud.gd` 加，纯 ColorRect/Label 组合，廉价画风）
   - NPC 牛/狼/陪练牛：头顶 3 颗心 Label3D（复用 BoulderBoss 的 Label3D 名牌方案）
3. **冲撞伤害规则**（接 `_on_charge_hit()`，新增 CharacterBody3D 分支）：
   - 无角：击退（velocity = 冲撞方向 × 10 + UP × 5），0 伤害
   - 初级角：正面（点积 > 0.5）= 1 血；侧/背面 = 击退无伤
   - 狂暴角：2 血 + 击飞（撞到树/石再弹开）
   - 连续对同一目标 3 次命中（间隔 ≤ 5 秒）→ **处决**：目标缩放消失 + 炸出马赛克方块粒子（CPUParticles3D，红色小方块）+ 屏幕大字"哞——杀！"（HUD 中央 Label，1 秒）+ 处决 CD 30 秒（角变灰提示）
4. **死亡表现**（荒诞调性）：
   - NPC 牛被撞死：原地旋转升天，越转越小（Tween scale→0 + rotation.y += TAU×5），"咻"（合成音效）
   - 玩家死亡：屏幕碎裂——全屏 ColorRect 白闪 3 帧 + 相机抖动（camera_rig 加 shake），黑屏 1 秒，嘲讽语随机（"你在梦里死了，但现实还在喝奶"等 5 条轮换），3 秒后在最近草丛复活，吃饱度减半

### P1-C 狼群危机（ChaosManager 新事件）

**改动文件**：`chaos/chaos_manager.gd`、新建 `chaos/wolf.gd`、`items/item_defs.gd`（3 个新道具）

1. **刷新调度**（挂在 ChaosManager，与黑洞并列）：
   - 自由模式开启后每 5-8 分钟判定一次：基础 15%；玩家 40 米内 NPC 牛 ≥ 5 只 → 25%；游戏时间 > 20 分钟 → 35%
   - 预警：地图边缘随机点生成 3 丛**高草丛**（放大 2 倍的草锥体），剧烈晃动 3 秒（rotation.z 正弦摇摆）+ HUD 提示"草丛里有东西……"
2. **抽象狼**（`wolf.gd` extends CharacterBody3D，1-3 只）：
   - 建模：拉长的 BoxBody + 歪嘴（一个斜着的白色小方块）+ 四条细腿（廉价棍状）——刻意丑
   - Bug 行为（复用 npc_cow 的 bug_mode 思路）：走路每 2 秒瞬移 0.5 米（瞬移=位置突跳，无动画过渡——就是要那种"卡了"的感觉）
   - AI：优先无角牛 → 血量最低者 → 玩家；冲刺前原地抽搐 3 次（0.8秒蓄力，身体快速小幅抖动）→ 飞扑
   - 咬中=秒杀（目标变"牛排骨"：棕色扁 Box 掉落，可拾取）
   - 弱点：被冲撞击退累计 5 次 → 晕眩原地转圈 10 秒（此时可被处决）；飞扑瞬间玩家穿模/幽灵 → 狼卡地消失（见 P1-A）
3. **掉落物**（`item_defs.gd` 加 3 个 + 掉落走 `drop_reward_near`）：
   - 狼牙（可堆叠）：集 3 颗在牛哥商店兑换"一次免死"（被咬时免疫+反震）
   - 狼皮：3 分钟狼不主动攻击你（狼绕着你转圈不上——把 AI 索敌半径内加"绕圈徘徊"状态）
   - 狼骨粉：狂暴角 60 秒（P1-B 的 2 级角道具）
4. **音效**：狼出现 → SfxBank 合成"跑调口哨"（正弦波 800-1200Hz 随机漂移 ±30 音分，8 秒循环，故意难听）

**P1 验收**：开局无角撞狼只能击退；吃石笋长角后能杀狼；3连撞处决弹"哞——杀！"；被咬变牛排骨死亡嘲讽复活；狼牙/狼皮/狼骨粉三件套可用。全程保持"廉价、抽象、Bug感"。

## 三、P2 联动玩法（P1 完成后）

1. **牛群护卫**：救下的 NPC 牛跟随玩家（≤3只，复制其 run_dir 逻辑改为追踪玩家），玩家冲撞时一起冲（0.5 秒延迟错峰），形成群体处决；跟随时"哞哞"声（合成音，音量=士气）
2. **战斗道具四件套**（接 ItemManager）：
   - 草盾：拾 10 捆草合成，右键举盾格挡一次狼扑，盾碎糊脸（屏幕边缘 1 秒草屑贴图遮挡）
   - 辣椒草：红色草丛（新草种，撞红色草丛掉落）→ 冲撞带火（拖尾粒子）灼烧狼，但自己视角抖 3 秒
   - 诱饵气球：飞天竞速奖励，漂浮充气牛（半透明 CowModel）吸引狼扑，扑中爆炸炸飞狼（狼记仇只追你）
   - 牛铃铛：隐藏洞穴（隐藏区墙的变体，可穿模进）内拾取，摇响召唤巨大野牛虚影（金色半透明放大 CowModel），无差别踩踏全图 5 秒——混沌事件的终极形态
3. **狼灾事件**（5% 概率替代普通狼）：5 只狼 + 雾霾（Environment.fog 动态开）+ 3 个防空洞入口（隐藏区墙变体，洞内有毒气扣血）——要么战要么逃要么赌
4. **墓碑复仇 buff**：NPC 牛被咬死后留墓碑（灰色小 Box + 十字），靠近 20 秒冲撞伤害 +50%
5. **现实模式彩蛋**：牛棚墙上挂狼牙项链（barn.gd 加一个挂件 mesh）；通关文案接入 Career 死亡计数："你在梦里死了 XX 次，但现实里一次都没死，这就是成长。"

## 七、竞技模式增强（P2 并行，与大逃杀等玩法）

**用户痛点**：大逃杀现在人人躲圈、相安无事——没有对抗手段，胜负全靠圈收缩"被动等死"。

### 7.1 现状根因（代码级）

| 模式 | 现状 | 问题 |
|---|---|---|
| 大逃杀 | [npc_royale_cow.gd](../scripts/modes/npc_royale_cow.gd) 陪练牛 AI 只有两种状态：圈内闲逛 / 圈外跑向圈心；玩家冲撞对它**无效**（`_on_charge_hit` 不处理 CharacterBody）；联机真人之间**没有任何互撞判定**（sumo 有，battle 漏了） | 零交互、零对抗 |
| 相扑 | 已有完整互撞（玩家撞陪练牛、陪练牛撞玩家、联机真人互撞——`sumo_arena.gd` L74-85 的快照距离判定 + "各客户端只判定我被谁撞了"哲学） | 基础好，可加深度 |
| 竞速/生存 | 纯 PVE 计时/躲避 | 优先级低，一句话方案见 7.5 |

### 7.2 架构决策：战斗核心发信号，模式决定死亡语义

P1-B 的冲撞战斗分支做成**全局通用 + 信号解耦**，各竞技模式只监听自己关心的结果：

```text
PlayerCow._on_charge_hit() 新增 CharacterBody3D 分支
    ├─ 伤害计算（角等级 × 正/侧面）+ 击退（velocity 直写）
    ├─ 连击计数 → 处决判定 → target.combat_defeated 信号（马赛克爆炸演出）
    └─ 播报 net.send_game_event({"type": "combat_hit", ...})

各模式监听 combat_defeated / 接 combat_hit：
    ├─ free 模式：NPC 牛死亡=旋转升天+掉草（原 P1-B 设计）
    ├─ battle：死亡=出局（rank 结算）+ 击杀播报；被击退飞出圈=双重惩罚
    ├─ sumo：**不走血量**（保持"一撞定胜负"的相扑纯粹性），只吃击退——血条归零下台太啰嗦
    └─ 竞技模式玩家自身血条照常生效（3 格，扣完出局）
```

这样战斗系统写一次，五个模式按需接线——不出现"每模式重写一套战斗"的复制粘贴灾难。

### 7.3 大逃杀竞技化（重点）

1. **陪练牛战斗 AI**（重写 NpcRoyaleCow 行为树）：
   - 圈内不再闲逛：随机锁定目标（玩家 60% / 其他陪练牛 40%——它们会内讧），8-15 米外绕行接近，6 米内直线冲撞（复用 NpcSumoCow 的 charge_cd 模式）
   - NPC 互撞：陪练牛撞陪练牛同样掉血出局，HUD 播报"陪练牛3 把 陪练牛5 撞成了马赛克"——玩家观战感+紧迫感双拉满
   - 阶段性狂暴：圈阶段 ≥ 3（半径 40 米以下）全体加速 20%、冲撞 CD 减半——"圈越小越疯"，后期节奏自动紧张
2. **真人互撞**（抄 sumo 的联机哲学，battle 补课）：
   - `battle_royale.gd` 的 `_physics_process` 加快照距离判定：对方 `act == "charge"` 且距离 < 2.3 → 我掉 1 血 + 沿撞击方向击飞（**击飞出圈=出局**——冲撞的最高价值不是杀死你，是把你送出加载区）
   - 被撞方客户端判定+播报（`type: "ko"` 通道现成），攻击方收到回执计击杀数
3. **角与道具进大逃杀**：
   - 石笋（长角）改空投补给刷新：无角=只能击退苟活，有角=有一战之力——"落地找武器"的经典吃鸡节奏
   - 空投池加狼牙（免死一次）+ 草盾（格挡一次冲撞）
4. **结算双榜**：名次按存活时间，平局看击杀数；HUD 常驻"剩余 N 头 · 你的击杀 K"
5. **处决在大逃杀**：处决演出照常（马赛克爆炸），且处决者恢复 1 血（战斗滚雪球的戏剧性收口）

### 7.4 相扑增强（轻量）

- **对撞互弹**：玩家冲撞 & 陪练牛同时处于 charge_timer → 双方反向弹开（后出手者多退 30%——拼时机，不是拼数值）
- **陪练牛流派**：每头随机流派——莽撞型（冲撞 CD 短 40% 但会冲过头冲出台）/ 守边型（赖在台边缘钓鱼执法，等你冲过来侧身让位）——台边阴人，相扑的"心机感"
- KO 目标不变（5 次），但播报文案区分击杀方式（撞飞 / 骗下台 / 对撞反弹）

### 7.5 竞速 / 生存（一句话方案，时间富余再做）

- 竞速：金环改窄 + 最后 3 环带"假金环"（穿错扣 2 秒——考察观察力，纯整活）
- 生存：陨石分三级 + 5% 红色追踪陨石（锁定最近目标追 3 秒——荒诞版导弹）
